Droo's Weekly Quests

Every Monday at 8 AM ET, Droo pins a new set of quests on the world map. They're all community goals: when chat clears one together, everyone in chat earns its EXP as nuts. Select a marker to see the quest and how close chat is to clearing it.

Quest log

    Quest progress updates while Droogle is live. Type !quests in chat for a quick summary.
